## 一、核心概念

### AIPPT 是怎么工作的？

```
你的模板 .pptx  →  ppt_meta_tool.py 解析  →  .meta.json（元数据）
                                                      ↓
用户的 business_data.json  →  SceneAdapter 适配  →  slot_data
                                                      ↓
                                            PptRenderer 渲染  →  成品 .pptx
```

**关键理解**：AIPPT 不"设计"PPT，它只是把你模板中的**占位文字**替换成**真实内容**，100% 保留原模板样式。

### 三个核心文件

| 文件 | 作用 | 谁生成 |
|------|------|--------|
| `模板名.pptx` | 你的 PPT 模板，包含占位文本 | **你手动制作** |
| `模板名.meta.json` | 描述模板结构（槽位在哪、什么类型、页码） | `ppt_meta_tool.py generate` 自动生成 |
| `模板名.pptx.png` | 首頁截图，供 Step 3 模板选择时预览 | `import_templates.py` 自动生成（需 PowerPoint） |

## 二、模板页面结构规范

### 2.1 必备页面类型

AIPPT 的 `ppt_meta_tool.py` 会**自动识别**以下页面类型。你的模板中**必须包含**这些页面，否则无法被正确匹配：

| 页面类型 | 识别方式 | 是否必须 | 说明 |
|---------|---------|---------|------|
| **封面页 (cover)** | 第 1 页强制识别 | ✅ 必须 | 含主标题、副标题、汇报人、日期等占位文本 |
| **目录页 (catalog)** | 含 `CONTENTS` 或 `目录` 等关键词 | ✅ 必须 | 列出各章节标题的占位列表 |
| **章节分隔页 (chapter)** | 含 `PART ONE` / `第1章` / `Part.01` 等 | ✅ 必须（至少 4 个） | 每个章节需要一个分隔页，含章节编号和标题 |
| **内容页 (content)** | 以上都不匹配的默认类型 | ✅ 必须 | 每个章节下 2-4 页内容页 |
| **结束页 (end)** | 末尾 5 页内含 `感谢聆听` / `THANK YOU` | ✅ 必须 | 含致谢语、汇报人等信息 |
| **版权页 (copyright)** | 末尾 3 页含版权关键词 | ⚠️ 可选 | 生成时会自动删除 |

### 2.2 推荐模板结构

一个 20 页的标准模板推荐结构：

```
第 1 页  → 封面页     （cover）
第 2 页  → 目录页     （catalog）
第 3 页  → 章节1分隔页（chapter）含 "PART ONE" 或 "01"
第 4 页  → 章节1内容页（content）
第 5 页  → 章节1内容页（content）
第 6 页  → 章节1内容页（content）
第 7 页  → 章节2分隔页（chapter）含 "PART TWO" 或 "02"
第 8 页  → 章节2内容页（content）
...
第 19 页 → 结束页     （end）含 "感谢聆听" / "THANK YOU"
第 20 页 → 版权页     （copyright，可选，生成时自动删除）
```

### 2.3 章节分隔页的写法（非常重要！）

系统通过以下关键词识别章节分隔页：

**强信号（推荐使用）**：
- `PART ONE`、`PART TWO`、`PART THREE`、`PART FOUR`
- `Part.01`、`Part.02`、`Part.03`、`Part.04`
- `PART.01`、`PART.02`、`PART.03`、`PART.04`
- `第1章`、`第2章`、`第3章`、`第4章`

**弱信号（需配合少量文本框 ≤ 6 个）**：
- `PART`、`第`、`章`

**数字+短中文标题模式（自动识别）**：
- 文本框数 ≤ 6 个
- 含纯数字 `01` ~ `09`
- 含 2~10 字中文标题

> ⚠️ **建议**：每个章节分隔页的文本框数量控制在 **6 个以内**，用 `PART ONE` 等强信号关键词，确保 100% 被识别。

## 三、占位文本规范

### 3.1 什么是槽位？

槽位 = 模板中等待被替换的占位文本。系统通过 `SLOT_MATCH_KEYWORDS` 列表识别哪些文本是"可替换的"。

### 3.2 推荐的占位文本（确保被识别）

在你的模板中，用以下文本作为占位内容，系统会 100% 识别：

#### 标题类占位
```
在此录入标题
请输入标题
添加标题
输入标题
单击输入标题
预设标题
TITLE HERE
```

#### 内容类占位
```
在此录入内容
请输入内容
单击此处输入你的正文
在这里输入你的正文
点此输入内容或者复制您的内容在这里
YOUR CONTENT IS ENTERED HERE
添加您的文本内容
```

#### 特殊字段占位
```
汇报人：              → 会被识别为 reporter 槽位
2O2X                  → 会被识别为 period 槽位（年份/周期）
2O2X年                → 会被识别为 period 槽位
```

#### 数字/百分比占位
```
01, 02, 03...         → 会被识别为 number 槽位
67%, 80%...           → 会被识别为 percent 槽位
2019, 2024...         → 会被识别为 year 槽位
```

### 3.3 占位文本语义化命名规则

系统会根据占位文本内容自动分配语义化槽位名：

| 你的占位文本特征 | 自动分配的槽位名 | 适用场景 |
|----------------|----------------|---------|
| 含"标题"/"TITLE"或短文本(<15字) | `title`, `title_2`, `title_3`... | 任何标题位置 |
| 含"内容"/"录入"/"输入"或长文本(>20字) | `desc`, `desc_2`, `desc_3`... | 描述/正文位置 |
| 纯数字如 `01`, `02` | `number`, `number_2`... | 编号/序号 |
| 纯年份如 `2019`, `2024` | `year`, `year_2`... | 时间轴年份 |
| 百分比如 `67%`, `80%` | `percent`, `percent_2`... | 数据百分比 |
| 含"汇报人"/"姓名" | `reporter` | 汇报人/作者 |
| 含"年度"/"202X"/"2O2X" | `period` | 时间周期 |

### 3.4 一个内容页的占位文本示例

以"三个要点 + 描述"的内容页为例，你这样写占位文本：

```
┌─────────────────────────────────────┐
│  [PART ONE / 章节标题占位]           │  ← title 槽位（短标题）
│                                     │
│  ┌──────┐ ┌──────┐ ┌──────┐        │
│  │  01  │ │  02  │ │  03  │        │  ← number 槽位（序号）
│  └──────┘ └──────┘ └──────┘        │
│  ┌──────┐ ┌──────┐ ┌──────┐        │
│  │在此录入│ │在此录入│ │在此录入│        │  ← title_2, title_3, title_4
│  │ 标题 │ │ 标题 │ │ 标题 │        │
│  └──────┘ └──────┘ └──────┘        │
│  ┌──────┐ ┌──────┐ ┌──────┐        │
│  │在此录入│ │在此录入│ │在此录入│        │  ← desc, desc_2, desc_3
│  │ 内容 │ │ 内容 │ │ 内容 │        │
│  └──────┘ └──────┘ └──────┘        │
└─────────────────────────────────────┘
```

## 五、完整制作流程

### Step 1：在 PowerPoint 中制作模板

1. 新建 PPTX，设置为 **16:9** 比例
2. 按[第二节](#二模板页面结构规范)的结构设计页面（封面→目录→4个章节→结束）
3. 按[第三节](#三占位文本规范)在每个需要替换的位置填入占位文本
4. 设计好看的样式（字体、颜色、布局、图标等）
5. 保存为 `.pptx` 文件

**⚠️ 制作时的关键检查清单**：

- [ ] 第 1 页是封面，含 `汇报人：`、`2O2X` 等占位文本
- [ ] 第 2 页是目录，含 `CONTENTS` 或 `目录` 文字
- [ ] 每个章节起始页含 `PART ONE`/`PART TWO` 等强信号
- [ ] 每个章节分隔页文本框数 ≤ 6
- [ ] 结束页（倒数 1-5 页）含 `感谢聆听` 或 `THANK YOU`
- [ ] 所有占位文本使用推荐的占位关键词（见 3.2 节）
- [ ] 如有版权声明页放在最后，含版权关键词

### Step 2：放到正确的分类目录

将模板文件放到 `models/<场景名>/` 目录下：

```
models/
├── 工作总结/
│   └── 你的模板.pptx        ← 放这里
├── 年终总结/
├── 工作汇报/
├── ...
```

> 如果不确定分到哪个类，可以放到一个临时目录，后续用 `import_templates.py` 自动分类。

### Step 3：使用 import_templates.py 批量导入（推荐）

```bash
# 从源目录批量导入模板，自动分类 + 生成 meta + 截图
python import_templates.py \
  --src "你的模板目录" \
  --prefix 商务风 \
  --removable-tail 1
```

参数说明：
- `--src`：源模板目录路径
- `--prefix`：模板重命名前缀（如 `商务风` → 文件名为 `商务风_001.pptx`）
- `--removable-tail N`：标记末尾 N 页为可删除（版权页），生成时自动删除
- `--no-screenshot`：如果没有安装 PowerPoint，跳过截图生成
- `--force`：覆盖已存在的模板

导入完成后自动完成：
1. 根据首页关键词自动分类到 10 大场景
2. 复制并重命名到 `models/<分类>/`
3. 生成 `.meta.json` 元数据
4. 生成首页 PNG 截图（需 PowerPoint）
5. 更新 `templates_index.json` 总索引

### Step 4：手动生成元数据（备选方案）

如果模板已经在 `models/` 目录下，直接用：

```bash
# 为单个或批量模板生成 meta.json
python ppt_meta_tool.py generate --dir models

# 强制重新生成（覆盖已有 meta）
python ppt_meta_tool.py generate --dir models --force
```

### Step 5：校验元数据质量

```bash
# 检查所有模板的 meta 质量
python ppt_meta_tool.py check --dir models
```

检查项：
- 必填字段完整性（template_id / category / total_pages / chapters / page_slots）
- 章节数量（< 2 会告警，说明章节分隔页未被识别）
- 槽位数量（< 5 会告警，说明占位文本未被识别）
- 版权页识别状态

### Step 6：更新总索引

```bash
# 重新生成 templates_index.json
python ppt_meta_tool.py index --dir models
```

### Step 7：验证模板可用性

```bash
# 查看模板详情，确认章节结构正确
python ppt_scene_adapter.py detail --template <你的模板ID>

# 用该模板渲染测试
python ppt_scene_adapter.py render \
  --scene <分类名> \
  --data business_<场景>.json \
  --template <你的模板ID> \
  --output test.pptx
```

## 六、关键注意事项

### 6.1 关于章节识别

> ⚠️ **这是最容易出问题的地方！**

系统通过 `ppt_meta_tool.py` 中的 `detect_page_type()` 函数识别页面类型。章节分隔页的识别优先级如下：

1. **强信号词**（最可靠）：`PART ONE`、`PART TWO`、`Part.01`、`PART.01`、`第1章`、`第2章`
2. **数字+短中文标题**（需文本框 ≤ 6 个）：如 `01` + `项目复盘`
3. **弱信号词**（需文本框 ≤ 6 个）：`PART`、`第`、`章`

**如果章节未被识别**，通常是因为：
- 章节页文本框超过 6 个（被误判为内容页）
- 没有使用强信号词
- 目录页含 `PART ONE` 等词（被误判为章节页）

### 6.2 关于槽位识别

系统通过 `SLOT_MATCH_KEYWORDS`（见 `aippt/constants.py`）识别可替换槽位。你的占位文本**必须包含**以下关键词之一才会被识别为槽位：

```
在此录入、请输入、添加标题、输入标题、请替换、您的内容打在这里、
在此处输入、添加文字、输入文字、请在此处添加、单击此处输入、
PROJECT –、TITLE HERE、YOUR CONTENT、ENTER HERE、预设标题、添加内容、
点击输入简要文字、请在此添加文字、单击此处添加、在这里说点什么、
点击添加标题、添加您的标题、请输入姓名、Text Here、添加小标题、
关键词标题、单击输入标题、在此输入标题、输入您的主要标题
```

### 6.3 关于容量计算

系统会自动计算每个槽位的文本容量（`capacity`），当替换文本超过容量时自动缩小字号。

- 容量基于 shape 的宽高和字号计算
- 如果 shape 太小（< 5 个字符容量），系统不会写入 capacity，由渲染器运行时估算
- **建议**：标题文本框至少能容纳 15 个中文字，描述文本框至少 60 个中文字

### 6.4 关于版权页

- 版权页（含"版权"、"包图网"、"1ppt"、"仅供学习"、"禁止商用"等关键词）会被自动标记为 `removable_pages`
- 生成 PPT 时默认自动删除这些页面
- 如果你希望保留，使用 `--keep-copyright` 参数

## 七、常见问题排查

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| **章节数为 0 或 1** | 章节分隔页未被识别 | 确保分隔页使用 `PART ONE` 等强信号词，文本框数 ≤ 6 |
| **槽位数量过少（< 5）** | 占位文本未被识别 | 检查占位文本是否包含 `SLOT_MATCH_KEYWORDS` 中的关键词 |
| **替换数为 0** | 模板 ID 不匹配或 meta 损坏 | 重新运行 `ppt_meta_tool.py generate --force` |
| **版权页未删除** | 版权关键词未命中 | 在末页加入"版权"、"仅供学习"等关键词，或手动编辑 meta 的 `removable_pages` |
| **文本溢出** | 内容过长 | 启用 `auto_fit=True`（默认开启），或增大模板中的文本框 |
| **封面字段未被替换** | 占位文本不匹配 | 封面的汇报人处使用 `汇报人：`，日期处使用 `2O2X` 或 `202X` |
| **目录页被误判为章节页** | 目录页含 PART/第N章 且文本框数 ≤ 6 | 增加目录页文本框数到 > 6，或确保目录页含 `CONTENTS`/`目录` |
| **生成后残留占位文本** | 该 shape 文本未被槽位关键词匹配 | 在模板中将该文本替换为包含关键词的占位文本 |
